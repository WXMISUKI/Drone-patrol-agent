# 无人机工地巡视智能体项目总纲

状态：阶段顺序已由用户确认；各阶段的具体范围、业务决策与验收仍待相关负责人确认。更新时间：2026-11-11。

本文件记录项目阶段方向与决策，不代替具体功能的 OpenSpec 规格、验收标准或实施任务。阶段可根据试点反馈回退调整；勾选必须基于实际成果，不能视为默认承诺。

## 项目方向

面向大范围、地形复杂工地，探索从无人机影像采集、AI 辅助发现、人工研判到整改复核和报告的业务闭环。用户、设备接入、现场流程、识别场景及交付边界均需进一步确认。参考资产及来源见 [资产登记表](../assets/资产登记表.md)，领导设想与初步研讨见 [项目启动草案](../docs/项目启动草案.md)。

## 文档职责

- `assets/` 保存参考资产及登记信息，参考内容不自动成为需求。
- `docs/` 保存研讨记录、产品需求、原型说明及决策材料。
- `openspec/project-roadmap.md` 保存跨阶段总方向；`openspec/changes/` 在范围明确后承载具体变更；归档后的 `openspec/specs/` 保存已确认的系统能力规格。
- 代码目录和技术规范待架构选择后建立，避免空目录暗示未经确认的技术方案。

## 最近决策点

先确认首个试点工程、目标使用角色、优先场景、可用影像与设备平台，以及整改台账归属；据此比较 MVP 路径。项目负责人确认后，再细化原型与技术方案。
