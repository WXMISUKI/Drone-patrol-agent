# 项目资产目录

请按类别将后续资料放入本目录，也可先放入 `待整理`，补充来源和使用说明后再归类。保留原文件名和版本，避免覆盖；参考原型仅供讨论，不代表最终效果。

| 目录 | 放置内容 |
| --- | --- |
| `待整理/` | 尚未分类或待补充说明的资料 |
| `需求与业务/` | 需求清单、业务流程、访谈记录、项目背景 |
| `原型与设计/` | 原型、页面截图、设计稿与交互说明 |
| `无人机与接口/` | 设备、机巢、航线、平台接口及部署资料 |
| `影像与样例/` | 获准使用的脱敏影像、识别样例与报告样本 |
| `标准与规范/` | 可使用的标准、监理细则、表单与适用范围说明 |

请在 [资产登记表](资产登记表.md) 中记录来源、版本、用途、敏感性及待确认事项。涉及凭据、个人信息或受限工程影像时，先确认存放权限及脱敏方式；不要将密钥提交到仓库。大文件和受限文件的存放及版本管理方式待确认。

现有外部资料已按类别复制到本目录，原目录保持不变。只读核对表明压缩包内 30 个文件与原型目录对应文件内容一致，压缩包未解压。资产的入库范围、使用权限及大文件管理方式仍需结合团队约定确认。
