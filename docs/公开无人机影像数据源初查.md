# 公开无人机影像数据源初查

日期：2026-11-12。用途：为无人机工地巡视 MVP 的影像可行性验证寻找公开材料。此为桌面初查，尚未下载或使用任何数据。

## 初步结论

本轮核实到的官方无人机数据集主要是通用城市场景/目标检测/语义分割数据，并非施工安全隐患数据。它们可用于验证无人机视角图像处理、目标尺度和视频帧流水线，不能替代五类施工隐患的人工确认样本，也不能直接作为业务准确率验收集。暂未找到同时满足“施工现场航拍、五类目标隐患、可靠标注、明确可商用许可”的公开数据集。

## 场景覆盖判断

- 深基坑/临边防护、高边坡/落石、越界开挖、工地人员防护、扬尘/裸土：上述数据源均未提供与项目定义一致的施工隐患标准答案。
- UAVid 的“人、道路、低植被”等只是通用分割类别，不等于安全帽/反光衣检测、裸土违规或施工边界判断。
- 搜索结果中的论文示例图、厂商宣传图或新闻航拍图，即使画面相关，也没有可复核标注；不能作为准确率样本。逐张图片的著作权/隐私/工程敏感性亦需核查。
- 公开数据可作为视觉链路/工程适配的候选素材。业务效果和验收应优先用客户授权、来源可追溯、由安全/监理人员确认的目标工地航拍图像。

## 建议的下一步

1. 先确认数据使用目的：只做人工浏览/流程演示，还是送入候选模型做识别试验。两者对许可和数据上传边界不同。
2. 对 UAVid 仅考虑非商业、许可允许的离线链路测试；不要将其上传至商业模型服务或并入产品训练，除非许可与服务条款另行确认。
3. 向客户/现场方申请少量脱敏、获准使用的原始航拍照片/视频，并请安全/监理人员标注“有隐患/无隐患/无法判断”及具体类别，作为无人机 MVP 的首轮业务验证材料。
4. 不把通用公开集成绩、监控系统约 60% 表现或未授权图片用作无人机业务验收指标。
